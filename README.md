# Soren Labs

Interactive science experiments for students.

## V1
15 Labs across Physics, Chemistry and Biology.

- Physics: Projectile Motion, Newton's Laws, Ohm's Law, Lens & Ray Optics, Waves & Sound
- Chemistry: Atomic Structure, Chemical Bonding, Reaction Rate, Acids & Bases, Electrolysis
- Biology: Cell Explorer, Human Heart, Respiratory System, Neuron & Reflex Arc, Photosynthesis

## Stack
React + TypeScript + Vite. SVG/Canvas-first visualizations with local simulation state for mobile performance.

## Principle
Learn science by testing it: manipulate variables, observe the model, then understand the concept.
