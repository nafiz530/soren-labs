# Soren Labs — Experiments

Each experiment lives in its own folder and should implement its scientific model separately from its presentation.

## First experiment: Acid–base titration

Route: `/labs/titration`

This first lab is a benchmark for the shared experience:
- Responsive layout and direct controls
- PlayCanvas scene with adaptive rendering resolution
- Measurements, observation log and theory
- Simulation speed control and experiment reset
- Lightweight presentation for mobile devices

The current 3D scene is an interactive visual prototype. Its pH/endpoint values are an illustrative teaching model, not a validated chemistry solver or a substitute for a real lab. Do not describe them as precision laboratory results.
